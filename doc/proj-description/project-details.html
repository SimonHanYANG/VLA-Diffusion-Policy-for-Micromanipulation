🔬 VLA Microscope Navigation

Vision-Language Guided Micro-Object Navigation via Conditional Diffusion Policy — Full Project Documentation

Goal

Train a conditional Diffusion Policy at scale in a simulated microscope environment, then transfer to real hardware (Nikon Ti2E).

Approach

CLIP text embeddings condition a 1D Conv U-Net that denoises action sequences. Observations encoded via ResNet-18. DDIM sampling at inference.

Scale

30 source files · ~3500 lines · 4 target types · 3 baseline policies · 2 visualization UIs · 7 config files · 4 CLI scripts

VisualEncoder src/vla/visual_encoder.py

ResNet-18 (pretrained on ImageNet). First convolution expanded to accept obs_horizon × 3 channels... Output: 256-dim feature vector.

TextEncoder src/vla/text_encoder.py

CLIP ViT-B/32 (frozen) via HuggingFace transformers. Task instructions encoded once and cached to data/text_embeddings.pt. Never loaded during training — only the 512-dim cached vectors are used.

TaskInstruction
microsphere"Navigate the microsphere to the red laser dot."
yeast"Navigate the yeast cell to the red laser dot."
sperm_head"Navigate the sperm head to the red laser dot."
sperm_tail"Navigate the sperm tail tip to the red laser dot."

ConditionalEmbedding src/vla/condition_embed.py

Concat(visual:256, text:512) = 768 → Linear(768, 512) → ReLU → Dropout(0.1) → Linear(512, 256) → ReLU → Dropout(0.1) → Linear(256, 256) → LayerNorm. Output: 256-dim condition vector.

NoiseScheduler src/vla/noise_scheduler.py

Training: Cosine beta schedule, T=100 steps. Precomputes α, β, ᾱ as registered buffers. Forward: x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε.

Inference: DDIM sampling with 10 steps (10× speedup). Deterministic reverse: x_{t-1} = √ᾱ_{t-1} · x̂_0 + √(1-ᾱ_{t-1}) · ε̂.

DiffusionUNet1D src/vla/diffusion_unet.py

Architecture: 1D convolutional U-Net with FiLM conditioning.

Input: Noisy actions (B, 2, 10) | Output: Predicted noise (B, 2, 10)

Encoder (3 DownBlock1D levels)

Each block: Conv1d(k5,s2) → GroupNorm → ReLU → Conv1d(k5,s1) → GroupNorm → FiLM → ReLU + residual. Channel progression: 64 → 128 → 256. Spatial: 10 → 5 → 3.

Bottleneck

Two Conv1d(k3) + GroupNorm layers with FiLM conditioning. No downsampling.

Decoder (2 UpBlock1D levels with skip connections)

Each block: Upsample(×2) → match spatial → Concat(skip) → Conv1d → GN → ReLU → Conv1d → GN → FiLM → ReLU + residual. Final Conv1d(dim, 2, k1) output projection.

FiLM Conditioning

Timestep embedding (128d sin/cos) → MLP(128, 256, 256). Concat with condition(256) → MLP(512, 256). Output: x * (1 + scale) + shift.

DiffusionPolicy src/vla/diffusion_policy.py

Training: compute_loss(obs_seq, action_seq, text_emb)

  1. Encode observations → visual features (256d)
  2. Fuse visual + text embeddings → condition vector (256d)
  3. Sample noise ε ~ N(0,I), timestep t ~ U(0,100)
  4. Noisify actions: x_t = scheduler.add_noise(x_0, ε, t)
  5. UNet predicts noise: noise_pred = UNet(x_t, t, cond)
  6. Loss = MSE(noise_pred, ε)

Inference: predict_action(obs_seq, text_emb)

  1. Encode → condition
  2. Start from random noise x_T ~ N(0,I)
  3. 10 DDIM steps: each predicts noise, then computes x_{t-1}
  4. Return x_0 as (B, pred_horizon=10, action_dim=2) predicted action sequence

Closed-Loop Inference

src/vla/inference.py:12-99

Algorithm / 算法:
  obs_history = [env.reset()]
  while not done:
      # Build obs_seq from last 2 frames
      obs_seq = stack(obs_history[-2:])  # (1, 2, C, H, W)
      action_seq = policy.predict_action(obs_seq, text_emb)  # (1, 10, 2)
      first_action = action_seq[0, 0]  # (2,) — receding horizon
      obs, reward, done, info = env.step(first_action)
      obs_history.append(obs)

Baselines

BCPolicy src/vla/baselines/bc.py

CNN (ResNet-18, 256d) → MLP(256→128→2). Predicts single-step (dx, dy) with MSE loss. Ignores text embeddings.

Params: ~11.5M

ACTPolicy src/vla/baselines/act.py

VisualEncoder(256d) → single memory token → Transformer decoder with 10 learned action query tokens. 4 encoder + 4 decoder layers. L1 loss on full sequence.

Params: ~15M

TrajectoryAugmentation src/data/augmentation.py

Consistent transforms across all observation frames:

  • Random horizontal flip (50%): flips images + negates action x-component
  • Brightness/contrast jitter (50%): factor 0.8–1.2 each
  • Gaussian pixel noise (30%): σ = 3.0

Trainer src/training/trainer.py

Optimizer: AdamW, lr=1e-4, weight_decay=1e-6.

LR Schedule: Cosine decay with 10-epoch linear warmup.

Gradient Accumulation: Configurable steps (default 1). Fixed to flush last batch.

Early Stopping: Patience=100 epochs on validation loss.

Checkpointing: Best → best.pt; periodic → epoch_XXXX.pt every 50 epochs.

Evaluation Metrics src/training/metrics.py

Success Rate

Fraction of episodes where distance < 2.0 px at termination.

Final Distance

Mean Euclidean distance (px) from target reference point to laser dot.

Smoothness

Mean absolute angular change between consecutive action vectors. Lower = smoother.

Key Design Decisions & Bug Fixes

Coordinate System

image_size = (H, W) but positions use (x, y) = (W, H) order.

U-Net Spatial Alignment

Horizon=10 → down(5, 3) → up(6, 12), plus final interpolation to restore horizon=10.

Motion Blur

Replaced incorrect np.apply_along_axis with proper 2D kernel + cv2.filter2D.

Gradient Accumulation

Added or last_batch condition in trainer.py to flush final partial accumulation.
